MatCOO benchmark documentation
=========================

Hello ! welcome to the MatCOO benchmark docs. The main purpose of this package is to 
show the differences of performance between `mat_coo_optim`, `mat_coo_pure`, 
the `scipy.sparse` implementation of COO matrix, and `numpy`.
